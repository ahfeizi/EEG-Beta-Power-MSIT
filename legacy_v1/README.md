# legacy_v1: as-run record of the v1 analysis

This folder is the **as-run record** of the analysis behind manuscript draft v1. That code was released as v1.0.0 (Zenodo, DOI 10.5281/zenodo.22232799).

**Do not use this code for new analyses.** It is kept so that every v1 result can be traced to the code that produced it, weaknesses included. The revision (v1.1) is in `../revision/`, and every correction is made there, with a decision-log entry in `../docs/decision_log.md`.

## What "as-run" means here

- **Source.** Each script is the copy that was actually executed on the analysis computer. This is not always the copy in release v1.0.0: several v1.0.0 files had been edited for publication without being rerun.
- **Path lines.** The only differences from the executed copy are path lines, each tagged `% [path]`:
  - local paths are replaced by `get_paths()` (see `../README.md`, "Configure paths");
  - every **output** goes to `<outRoot>/legacy_v1_rerun/`, so a rerun can never overwrite the v1 derivatives;
  - the local Python/FOOOF paths (`pyenv`, `addpath(fooof_mat)`) in `extract_IBF_full42.m` and `exploratory/extract_IBF.m` are commented out. Set up FOOOF as described in `../README.md` before running these two.
- **Verification.** The tagged-line rule was checked file by file. In all 32 scripts:
  - every added line carries `% [path]`;
  - every removed line is a path line;
  - MATLAB `checkcode` reports no new message compared with the executed copies.
- **Empirical test.** Stage 2, pass 1, of the revision reruns the statistics scripts unchanged and compares their outputs byte-for-byte with the v1 derivatives. The results will be recorded in `../docs/decision_log.md`.

## Tests that used the normal approximation

With n = 42, MATLAB's `signrank` uses the large-sample normal approximation unless `'method','exact'` is given. The executed code used:

| Script | Test | Line | Approximation | Reported in draft v1 |
|---|---|---|---|---|
| `statistics/beta_channel_stats_emg_test.m` | one-sample Wilcoxon per channel (channel screening) | `signrank(row)` | normal | yes (Channel Screening p-values) |
| `statistics/conflict_specificity_prestim_beta.m` | Wilcoxon FS vs 00 | `signrank(M(:,4), M(:,1))` | normal | yes ("all p > .11") |
| `statistics/conflict_specificity_prestim_beta.m` | Page's L trend test | `pages_trend_test` | one-sided normal | yes (Cz p = .039) |
| `statistics/effect_size_rankbiserial.m` | Z and r = Z/√N only | second `signrank` call | normal | no (Table 2 p uses `'exact'`) |
| `exploratory/statComparison_beta_power_MSIT_4Conds.m` | post-hoc pairwise Wilcoxon | `signrank(...)` | normal | no |

The control-band comparison in `statistics/tost_control_band_equivalence.m` is a paired t-test on log10(task/rest), not a Wilcoxon test.

## Rerunning (if ever needed)

- **Outputs.** Every output goes to `<outRoot>/legacy_v1_rerun/` (`rerunDir`). Scripts read v1 inputs from `derivRoot` / `taskDeriv`.
- **Preprocessing.** `preprocessing/preprocess_rest_eeglab_staged_Pilot.m` writes its per-subject `.set` files to `rerunDir`, but downstream scripts still read the v1 `.set` files from `derivRoot`. To rerun the whole chain, point `derivRoot` (in `config_local.m`) at the rerun folder first.
- **`exploratory/extract_IBF_rawPSD.m`.** As run, it wrote one PNG per subject into each `sub-XX` folder; a rerun writes them flat into `rerunDir`.
- **Software.** MATLAB R2022b; Python 3.10 with `fooof` for the FOOOF scripts.
  - The EEGLAB installation on the analysis computer's MATLAB path, checked on 2026-10-02, is EEGLAB 2023.0 (CleanLine 2.1, PICARD 2.0, ICLabel 1.6, clean_rawdata 2.91, firfilt 2.8).
  - That the same versions were used in July–August 2026 is likely but was not logged at the time.
